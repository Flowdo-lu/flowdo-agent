# Agent Flowdo — installeur Windows

Ce dépôt ne contient **que les versions publiées** (onglet *Releases*) de l'installeur Windows de
l'agent local Flowdo. Le code source est dans un dépôt privé.

- Télécharger : https://github.com/Flowdo-lu/flowdo-agent/releases/latest/download/FlowdoAgent.exe
- Chaque release donne la somme SHA-256 du fichier et le build qui l'a produit.
- N'installe l'agent que depuis cette adresse (`github.com/Flowdo-lu/`). Le site todos.flowdo.lu
  ne sert jamais l'exécutable : il affiche seulement le code d'installation à coller au premier lancement.
- Binaire non signé : Windows affiche « Windows a protégé votre ordinateur » → « Informations
  complémentaires » → « Exécuter quand même ».
